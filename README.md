# Политика конфиденциальности приложения «Смыслы»

Страница политики конфиденциальности для головоломки «Смыслы»
(`com.smysly.smysly`), публикуемая через GitHub Pages.

- Готовый адрес после включения Pages: <https://happyvolkovajulia-ai.github.io/smysly-privacy/>
- Исходная страница: [`index.html`](index.html)

Приложение работает офлайн, не запрашивает доступ в Интернет и не собирает
персональные данные. В локальном хранилище устройства сохраняется только игровой
прогресс: дата первого запуска, решённые головоломки, стрик и настройки.

## Как обновить

1. Отредактировать `index.html`.
2. Закоммитить и отправить в ветку `main` — страница на GitHub Pages обновится
   автоматически в течение пары минут.
